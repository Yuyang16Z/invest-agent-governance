# 演示视频脚本（约 128 秒）

视频由 `npm run video`（`scripts/record-demo.ts`）自动录制：Playwright 驱动产品逐页操作，字幕直接叠加在页面上，ffmpeg 输出 `video/demo.mp4`（1440×900，H.264）。下表时间点取自录制日志，四舍五入到秒。

| 时间 | 页面 | 操作 | 字幕要点 |
|---|---|---|---|
| 0:00–0:05 | 总览 | 片头 | 6 个 Agent 版本、192 条 DeepSeek 真实回答、扶摇数据逐个核验数字 |
| 0:05–0:24 | 总览 | 看本期结论与闸门 → 评测链路分工图 → 悬停版本演进图 | 4 条结论由数据现算；规则/LLM/扶摇核验/人工复核/用户反馈各管什么；悬停看分子/分母 |
| 0:24–0:38 | 评测记录 `V1-QT01-U03` | 看高亮回答与数字核验表 | “1263 元、+0.57%、44.53 亿”都等于 10-09 的旧数据 → 根因“数据时效” |
| 0:38–0:46 | 评测记录 `V3-AD07-U04` | 看 REL-TRUNC | 回答写到一半被截断，结尾的风险提示丢失 → 根因“输出截断” |
| 0:46–0:59 | 版本对比 V3→V6 | 结论条、组件差异、配对检验 | 只改输出上限：整体 18→28/32（+31pp，p=0.006），闸门通过 |
| 0:59–1:07 | 版本对比 V3→V4 | 结论条 | 换模型同时改了上限（多因素）；对照 V6，模型贡献不明显；画像不变性 2/4 → 阻断 |
| 1:07–1:22 | 画像一致性 | G-FD01 与不变事实清单 | C1 用户的回答漏了风险提示；列出不能因画像改变的事实 |
| 1:22–1:32 | 人工复核 | 打开 `V4-FD01-U01`，逐维度同意、写说明、保存 | 只看被路由进来的回答；推翻率用于校准 |
| 1:32–1:50 | 在线评测 | 依次运行“合规越界”“否定语境”“接口异常” | 红线命中；否定语境不误报；接口超时降级为“无法核验”并送人工 |
| 1:50–2:02 | 质量标准 | 浏览标准、分工与扶摇调用记录 | 71 次真实调用、每条事实带 request_id；回撤接口全 0 判为未就绪并改为推算 |
| 2:02–2:08 | 总览 | 片尾 | 在线地址与仓库地址 |
