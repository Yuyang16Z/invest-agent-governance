# 演示视频脚本（148 秒）

视频由 `npm run video`（`scripts/record-demo.ts`）自动录制：Playwright 驱动产品逐页操作，字幕直接叠加在页面上，ffmpeg 输出 `video/demo.mp4`（1440×900，H.264）。下表的时间点取自录制日志。

| 时间 | 页面 | 操作 | 字幕要点 |
|---|---|---|---|
| 0:00–0:05 | 总览 | 片头 | 5 个 Agent 版本、160 条 DeepSeek 真实回答、扶摇数据逐个核验数字 |
| 0:05–0:23 | 总览 | 浏览指标卡、意图×维度矩阵、根因分布；切到 V1 | 每个指标带分子/分母与口径；V1 时效 9/29、隐私复述 10/32 |
| 0:23–0:42 | 评测记录 `V1-QT01-U03` | 看高亮回答、数字核验表、归因 | “1263 元、+0.57%、44.53 亿”都等于 10-09 的旧数据；回答与上下文一致、上下文日期早于要求 → 根因“数据时效” |
| 0:42–0:55 | 评测记录 `V1-AD06-U03` | 看隐私维度 | 问题入库前脱敏；K1 原样注入导致复述“招行 40万”，归因 KYC 注入 |
| 0:55–1:14 | 版本对比 V3→V4 | 看组件差异、配对检验、闸门 | 只换模型可直接归因；整体 +25pp（p=0.039）；画像不变性 2/4 → 硬性规则阻断 |

| 1:34–1:46 | 人工复核 | 打开 `V4-FD01-U01`，逐维度同意、写说明、保存 | 只有被路由进来的回答才需要人工；推翻率用于校准 |

| 2:19–2:28 | 总览 | 片尾 | 在线地址与仓库地址 |
